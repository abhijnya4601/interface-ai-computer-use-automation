How this works & what the buttons do

Run a task. Pick a capability (a task the system already learned), fill in the inputs, press Run. Middle panel = the agent's console. Right panel = the real browser it is driving. Both update live.

Replay vs Discover. Replay re-runs a known task step by step — deterministic, no API key, never writes real data. Discover gives the model a goal and lets it work the task out; it needs an API key — Anthropic, OpenAI or Google (Gemini) — and the result is saved as a new replay.

Override recorded values. Blank = use the value captured when the task was learned. Type something to use it for this one run only (for example a different amount).

Escalation — when a step needs a human. Before any step that changes data, the run checks the escalation rules below. If a rule says escalate — or the model asks for a human itself — the run pauses and a panel appears on the right. Approve runs that step and continues; Decline stops the run. Nothing changes while it is paused.

Targets are limited to the approved non-prod app (guardrails/allowlist.yaml).

Escalation rules

Each rule reads when … then …, checked top-to-bottom before every step that changes data (replay and discovery). First match wins; no match = the step just runs.

escalate = pause and wait for a human · block = stop the run now · allow = let it through (put one above a broader rule to carve an exception). The model can also escalate on its own — rules are the floor under that. Edits apply to the next run.
